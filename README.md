# Lizneida Cordero | Educación y orientación de la conducta

Sitio web profesional desarrollado con React, TypeScript y Vite.

## Requisitos

- Node.js 22.12 o posterior

## Ejecutar en local

1. Instala las dependencias: `npm install`
2. Inicia el servidor de desarrollo: `npm run dev`
3. Abre [http://localhost:3000](http://localhost:3000)

No se necesita una clave de Gemini ni un archivo `.env.local` para ejecutar el sitio.

Para comprobar tipos y generar la versión de producción, ejecuta `npm run lint` y `npm run build`.
